# SQLD양파 (sqldyangpa.com) 기출문제 크롤러 & 데이터셋

[SQLD양파](https://sqldyangpa.com/) 웹사이트에 수록된 SQLD(SQL 개발자) 자격검정 기출 복원 문제 전체와 CBT 모의고사를 수집하고, `question-bank` 표준 포맷으로 변환하는 모듈입니다.

---

## 1. 수집 데이터 요약

- **출처**: [https://sqldyangpa.com/](https://sqldyangpa.com/)
- **기출 회차**: **제45회(2022년 5월) ~ 제60회(2026년 3월)** (총 16개 회차)
- **기출 문항 수**: **800문항** (회차당 50문항: 1과목 10문항, 2과목 40문항)
- **추가 수집**: **AI 모의고사 1,331문항**
- **문항 구성 요소**:
  - 문항 질문 및 4지선다 보기
  - 정답 번호 (1-based index)
  - 상세 해설
  - 지문 (텍스트, SQL 코드 블록, Markdown 테이블 표, Mermaid ERD 다이어그램, ASCII 다이어그램)
  - 보기별 지문 (옵션별 ERD 다이어그램, 테이블 표)

## 2. 파일 및 폴더 구조

```text
macro/sqld_yangpa/
├── crawler.js             # Node.js 메인 크롤링 & 변환 스크립트
├── crawler.py             # Python 실행 래퍼 스크립트
├── README.md              # 가이드 문서
│
├── sqld_yangpa_raw.json   # 16개 회차(800문항) 원본 데이터 및 메타데이터
├── sqld_ai_mock_raw.json  # AI 모의고사(1,331문항) 원본 데이터
├── sqld_yangpa_all.json   # question-bank 표준 통합 포맷 (SQLD_45 ~ SQLD_60)
│
└── rounds/                # 회차별 독립 문제 세트 파일 ({"problems": [...]})
    ├── round_45/
    │   └── round_45.json  # 제45회 50문항
    ├── round_46/
    │   └── round_46.json  # 제46회 50문항
    ...
    └── round_60/
        └── round_60.json  # 제60회 50문항
```

## 3. 실행 방법

### 방법 1: Node.js로 실행
```bash
node macro/sqld_yangpa/crawler.js
```

### 방법 2: Python으로 실행
```bash
python macro/sqld_yangpa/crawler.py
```

스크립트 실행 시 다음 작업이 자동으로 수행됩니다:
1. `https://sqldyangpa.com/` 접속 및 최신 Vite 번들 JS 파일 URL 동적 탐색
2. 번들 JS 다운로드 및 16개 회차 기출문제 / AI 모의고사 파싱
3. 원본 JSON (`sqld_yangpa_raw.json`, `sqld_ai_mock_raw.json`) 생성
4. Markdown 표, SQL 블록, Mermaid ERD 다이어그램 파싱 및 `question-bank` 표준 스키마 매핑
5. 통합 파일(`sqld_yangpa_all.json`) 및 회차별 파일(`rounds/round_XX/round_XX.json`) 생성
